# Content Rules — non-negotiable

These rules govern every week generated in `week_content.py`. Do not break them.

## Business context
- **Niche:** local service businesses (plumbers, HVAC, roofers, landscapers,
  cleaners, detailers, etc.).
- **Offer:** $1,500/mo for 30 appointments, *or* $500 up front + $35/appointment.
- **The machine we sell:** Meta Ads → landing page → text-follow-up automation →
  booked calendar → the client's tech shows up to the job/estimate.
- Everything is about the niche's world — their jobs, their customers, their
  money, their calendar. **Never generic marketing talk.**

## The 4 content rules
1. **Hard hooks.** Under ~10 words when possible. A number or an enemy in the
   first line. Direct "you." Bold enough to sting.
   - Weak: "There's one mistake that kills most ads."
   - Strong: "This ad burns $1,000 a month in its first 3 seconds."
2. **Open loop on every script.** The hook names something the viewer does NOT
   know (a specific mystery: "one mistake", "a number", "the exact five words")
   *without revealing it*. The body builds toward it. The answer only lands in
   the FINAL lines. Never give the payoff away early.
3. **STAR format on every Talking Head**, written into the script with labels:
   - `[S — SHOCK, spoken]` — shocking spoken opener (this is the hook)
   - `[T — TEXT HOOK on screen]` — on-screen text hook, **different wording** than spoken
   - `[A — ACHIEVEMENT]` — a real result / credibility statement
   - `[R — ROADMAP]` — a uniquely named roadmap nobody has heard of + a promise
     of what they get by watching to the end
   - `[RECIPE]` — the actual numbered steps
   - `[LOOP CLOSE]` — the reveal, tied back to the named roadmap
4. **One line per breath.** Scripts are written one short line per breath.

## Naming
- Every Friday framework and every Talking-Head roadmap gets a unique,
  proprietary-sounding name (e.g. "The 300-Second Window", "The Appointment
  Engine", "The Filter Funnel"). Log names in `ARCHIVE.md` so they never repeat.

## Formats (rotate across the week; NO carousels)
Talking head · Green screen (screenshot/proof on screen) · Reaction (to a real
ad or bad-advice clip) · Split screen (two owners: one wrong, one right) · Clone
(you playing both characters) · Miro board (drawing a framework live) · Overlay
text (numbers/checklist over b-roll).
- Use **Clone ~2×/week** and **Miro ~2×/week**.
- Each day Mon–Sat = **4 videos**; video #1 is the Talking Head (STAR).

## Weekly themes (fixed)
| Day | Theme | Job |
|-----|-------|-----|
| Monday | One Specific Fix | Teach one concrete fix |
| Tuesday | Before & After | Real client proof / case study |
| Wednesday | The Pain | Agitate the problem |
| Thursday | Behind The Scenes | Show the work / process |
| Friday | The Framework | A named, drawn-out system |
| Saturday | Objection Crusher | Destroy one common objection |
| Sunday | Rest / Repurpose | Note only, no scripts |

## Daily IG Stories (3 per day)
1. A **poll** that segments the audience.
2. A **proof/BTS** or **agitate** text slide tied to that day's videos.
3. A **CTA** slide using that day's DM keyword.
- **Thursday** uses a **Q&A box** instead of the CTA slide.

## DM keywords
One per day Mon–Sat. Punchy, single word, all-caps. Fresh set is fine each week.
This week: FIX · PROOF · LEAKS · SYSTEM · PLAYBOOK · BOOKED.

## Story image style
1080×1920. Photo background + ~25% black overlay. Rounded text boxes anchored
upper-middle. White box = near-white fill / dark text. Dark box = dark fill /
white text. Inline markup `[r]pain[/] [g]win[/] [o]dm-keyword[/]`. `@handle`
bottom-left, `n/N` bottom-right. Content mirrors the Notion week exactly.
